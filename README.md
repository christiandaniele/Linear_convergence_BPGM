# Linear convergence of Bregman proximal gradient methods

This repository contains the numerical experiments for **“On the Linear
Convergence of Bregman Proximal Gradient Methods with Applications to
Kullback–Leibler Regression.”** https://arxiv.org/pdf/2607.05539

The code compares BPGM with Burg entropy, BPGM with smoothed Burg entropy,
Euclidean proximal gradient, and Richardson–Lucy on synthetic KL regression
problems.

## Experimental regimes

The problem dimension is fixed to `N=500`. The two inputs `M` and `lambda`
select the four principal regimes:

| Regime | Parameters |
|---|---|
| Full rank, unregularized | `M=500`, `lambda=0` |
| Full rank, regularized | `M=500`, `lambda>0` |
| Rank deficient, unregularized | `M<500`, `lambda=0` |
| Rank deficient, regularized | `M<500`, `lambda>0` |

The experiments in the paper use `M=400` in the rank-deficient setting and
`lambda=0.1` in the regularized setting.

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run one experiment

For example, Figure 5 is generated by the rank-deficient regularized setting:

```bash
python scripts/run_experiment.py \
    --M 400 \
    --lambda 0.1 \
    --solution boundary \
    --name figure_5_rank_deficient_regularized
```

The numerical arrays are written to `results/data/` and the PDF figure to
`results/figures/`.

For a quick smoke run, reduce the number of trials and iterations:

```bash
python scripts/run_experiment.py \
    --M 20 \
    --lambda 0.1 \
    --trials 2 \
    --iterations 100 \
    --plot-iterations 100 \
    --name smoke_test
```

## Reproduce Figures 3--6

```bash
python scripts/reproduce_all.py
```

The smoothing-parameter study in Figure 2 is run separately:

```bash
python scripts/sweep_xi.py --M 500 --lambda 0
```

The full command uses 30 initializations and 200,000 iterations per method, as
specified in the paper, and can therefore take considerable time.

## Correspondence with the paper

| Figure | Setting |
|---|---|
| Figure 2 | `M=500`, `lambda=0`; sweep over the smoothed-Burg parameter `xi` |
| Figure 3 | `M=400`, `lambda=0`, rank deficient |
| Figure 4a | `M=500`, `lambda=0`, interior solution |
| Figure 4b | `M=500`, `lambda=0`, boundary solution |
| Figure 5 | `M=400`, `lambda=0.1`, rank deficient and regularized |
| Figure 6a | `M=500`, `lambda=0.1`, interior solution |
| Figure 6b | `M=500`, `lambda=0.1`, boundary solution |

The rank-deficient regularized experiment is restricted to the boundary case,
consistently with Remark 3.9 of the paper.
